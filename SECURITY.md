# Security policy / Sigurnosna politika

## Supported versions / Podržane verzije

Security fixes target the latest tagged Simbioza release. Older releases may
need to update to receive a fix. The independently released modules used by
Simbioza have their own versions; include the installed module versions when
reporting an issue. This policy does not promise a fixed response or repair
time.

Sigurnosni popravci usmjereni su na najnovije označeno izdanje Simbioze.
Starije instalacije možda će trebati nadograditi. Moduli koje Simbioza koristi
imaju vlastite verzije; pri prijavi navedite i verzije instaliranih modula.
Ova politika ne jamči rok odgovora ili popravka.

## Report privately / Prijavite privatno

Please use [GitHub's private vulnerability reporting](https://github.com/kmihalj/Simbioza/security/advisories/new)
or email [kmihalj@mac.com](mailto:kmihalj@mac.com).
Do not open a public issue or pull request containing exploit details, secrets,
private data, or an unfixed vulnerability.

Za prijavu upotrijebite [GitHubovu privatnu prijavu ranjivosti](https://github.com/kmihalj/Simbioza/security/advisories/new)
ili pišite na [kmihalj@mac.com](mailto:kmihalj@mac.com).
Nemojte otvarati javni issue ili pull request s detaljima iskorištavanja,
tajnama, privatnim podacima ili neispravljenom ranjivošću.

Please include the affected release and module versions, deployment type,
impact, minimal reproduction steps, and whether the issue has been disclosed
elsewhere. Use synthetic data; do not send production credentials or personal
information. The maintainer will coordinate investigation and disclosure with
the reporter where practical.

Navedite zahvaćeno izdanje i verzije modula, način instalacije, učinak,
minimalne korake za ponavljanje te je li problem već drugdje objavljen.
Koristite sintetičke podatke; nemojte slati produkcijske pristupne podatke ni
osobne podatke. Održavatelj će, kada je to izvedivo, uskladiti provjeru i
objavu s prijaviteljem.

For ordinary bugs and usage questions, see [SUPPORT.md](SUPPORT.md).
Za obične greške i pitanja o korištenju pogledajte [SUPPORT.md](SUPPORT.md).
