# Security policy

[Croatian version](SECURITY_hr.md)

## Supported versions

Security fixes target the latest tagged Simbioza release. Older releases may
need to update to receive a fix. The independently released modules used by
Simbioza have their own versions; include the installed module versions when
reporting an issue. This policy does not promise a fixed response or repair
time.

## Report privately

Please use [GitHub's private vulnerability reporting](https://github.com/kmihalj/Simbioza/security/advisories/new)
or email [kmihalj@me.com](mailto:kmihalj@me.com). Do not open a public issue or
pull request containing exploit details, secrets, private data, or an unfixed
vulnerability.

Include the affected release and module versions, deployment type, impact,
minimal reproduction steps, and whether the issue has been disclosed
elsewhere. Use synthetic data; do not send production credentials or personal
information. The maintainer will coordinate investigation and disclosure with
the reporter where practical.

For ordinary bugs and usage questions, see the
[support guide](SUPPORT.md).
