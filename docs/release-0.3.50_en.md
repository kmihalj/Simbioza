# Simbioza 0.3.50 — MD Editor and Workspace navigation

> Historical release note for an unpublished candidate. See the [current release](release-0.3.51_en.md).

MD Editor **0.3.1** supports standalone Markdown pages and embeddable Markdown fields. It includes revisions, translations, attachments and an API for standalone and Workspace pages. Workspace **0.3.10** supports both editor formats in the same tree. HTML Editor **0.3.22** includes the shared outline controls and the updated attachment upload defaults.

Workspace measures the page-tree labels and outline headings to size each side card within a readable range. The page uses the available space. When there is too little room to read the page alongside the cards, the edge buttons open the tree and outline as drawers.

The **Editing pages** chapter includes HTML Editor and MD Editor guides in the six supported languages. Croatian and English have screenshots in the corresponding interface language.

An upgrade from 0.3.48 prepares the Markdown schema. On Demo, the Demo support tools also activate the module. On other existing installations, open **Settings → Modules and checks** and install or enable **MD Editor**.

See [installation](installation_en.md), [Docker deployment](docker_en.md) and the [theme collection](https://github.com/kmihalj/Simbioza/releases/download/0.3.50/Simbioza-0.3.50-themes.zip).
