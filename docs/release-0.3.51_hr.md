# Simbioza 0.3.51 — MD Editor i navigacija u područjima

> Povijesna bilješka izdanja. Pogledajte [aktualno izdanje](release-0.3.53_hr.md).

MD Editor **0.3.1** podržava samostalne Markdown stranice i ugradiva Markdown polja. Uključuje povijest, prijevode, privitke i API za samostalne stranice i stranice u područjima. Područja **0.3.10** podržavaju oba formata u istom stablu. HTML Editor **0.3.22** uključuje zajedničke kontrole kazala i dopunjene zadane postavke prijenosa privitaka.

Širine stabla stranica i kazala prilagođavaju se duljini naziva unutar čitljivog raspona. Stranica koristi preostalu širinu. Kad nema dovoljno mjesta za istodobno čitanje stranice i prikaz kartica, stablo i kazalo otvaraju se rubnim gumbima.

Poglavlje **Uređivanje stranica** sadrži upute za HTML Editor i MD Editor na svih šest podržanih jezika. Hrvatska i engleska uputa imaju snimke zaslona na odgovarajućem jeziku.

Nadogradnja s 0.3.48 priprema shemu za Markdown. Na Demu alati za pripremu ujedno aktiviraju modul. Na ostalim postojećim instalacijama u **Postavke → Moduli i provjere** instalirajte ili uključite **MD Editor**.

Pogledajte [instalaciju](installation_hr.md), [Docker](docker_hr.md) i [paket tema](https://github.com/kmihalj/Simbioza/releases/download/0.3.51/Simbioza-0.3.51-themes.zip).
