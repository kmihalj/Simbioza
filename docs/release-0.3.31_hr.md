# Simbioza 0.3.31 — postavke skripti i kontrole tablica usklađene s temom

> Povijesna bilješka izdanja. Pogledajte [aktualne upute za instalaciju](installation_hr.md) i [Simbiozu 0.3.43](release-0.3.43_hr.md).

[Engleska verzija](release-0.3.31_en.md)

Postavke skripti HTML editora koriste boje pozadine koda, teksta i obruba aktivne teme. Ugniježđeni kod više nema zasebnu obojenu traku. Isječci za učitavanje biblioteke i neobavezni kod za pokretanje prate svijetli i tamni način prikaza.

Paginacija tablica DataTables prikazuje strelice za prvu, prethodnu, sljedeću i zadnju stranicu, uz očuvanje izvornih lokaliziranih pristupačnih naziva. Oznake sortiranja koriste paletu zaglavlja tablice: dostupni smjerovi vidljivi su prije sortiranja, a aktivni smjer je naglašen. Obične tablice ostaju iste.

Dorade se primjenjuju kroz CSS teme. Postojeće odobrene definicije DataTablesa, identifikatori skripti, provjere integriteta i odabiri po stranicama ostaju sačuvani. Nadogradnja ne odobrava niti uključuje skripte.

Uključuje HTML Editor **0.3.12** i Theme **0.3.8**. Framework ostaje **0.0.25**. Nema nove migracije baze ni resetiranja konfiguracije. Instalacijske upute i njihove isporučene kopije koriste aktualno izdanje i popis modula. Vidi [instalaciju](installation_hr.md) i [ovisnosti modula](module-dependencies_hr.md).

Svijetli i tamni prikaz, hrvatske i engleske kontrole, sortiranje tipkovnicom, paginacija i nepromijenjene obične tablice provjereni su ugrađenim preglednikom. Provjere modula, CI aplikacije, očuvanje pri izdvojenoj nadogradnji i paketi izdanja zasebno se provjeravaju prije objave.
