# Simbioza 0.3.8 — unpublished candidate

> Historical release note. For current installation instructions, use the [installation guide](installation_en.md).

The 0.3.8 tag records an intermediate candidate. Its GitHub release was not
published, and no stable Docker image was published for it. Final secured-FPM
verification found an additional private-configuration permission issue.

Use [Simbioza 0.3.9](release-0.3.9_en.md), which includes the complete settings
and theme-color fixes. The 0.3.8 tag is retained unchanged; do not use it as
the installation or update target.
