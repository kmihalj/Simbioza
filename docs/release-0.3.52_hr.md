# Simbioza 0.3.52 — prikaz editora preko cijelog zaslona

MD Editor **0.3.2** i HTML Editor **0.3.23** zadržavaju alatnu traku vidljivom pri uređivanju preko cijelog zaslona. Uz ljepljivo zaglavlje ili navigaciju tema smješta okvir neposredno ispod njih. Vizualni prikaz i izvor ispunjavaju preostalu visinu, a dugi dokumenti pomiču se do posljednjeg retka unutar polja.

Provjeren je prikaz s uključenim modulom Pristupačnost i s tekstom povećanim na 125 %. Izdanje uključuje upute za oba editora iz [0.3.51](release-0.3.51_hr.md).

Pogledajte [instalaciju](installation_hr.md), [Docker](docker_hr.md) i [paket tema](https://github.com/kmihalj/Simbioza/releases/download/0.3.52/Simbioza-0.3.52-themes.zip).
