<a id="for-developers--api"></a>


> Le schermate mostrano l’interfaccia in inglese.

[Sondaggi](ankete_it.md)

Questa sezione riguarda l'integrazione di altri sistemi con Simbioza. API non è richiesto per la creazione o la partecipazione ordinaria.

1.  [API — esempi di cURL](ankete-api_it.md)
2.  [API — PHP esempi per la tua applicazione](ankete-api-php_it.md)
3.  [Percorsi, ambiti ed errori](ankete-api-referenca_it.md)
4.  [Modello di definizione ed esempi di risposta](ankete-api-primjeri_it.md)
5.  [HTML contenuto e limite di sicurezza](ankete-html-sadrzaj_it.md)

Gli esempi usano il segnaposto `https://simbioza.example`. Sostituiscilo con l'indirizzo dell'installazione e l'eventuale sottocartella. Non sono necessari HFC né sondaggi di esempio preesistenti.

API gestisce le definizioni, la pubblicazione e la lettura dei risultati autorizzata. Una chiave non può inviare risposte come un'altra persona o sostituire l'accesso del partecipante.
