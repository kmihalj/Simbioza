Examples use the placeholder `https://simbioza.example`. Replace it with your installation address and any subdirectory. Neither HFC nor pre-existing sample surveys are required.

The API manages definitions, publication and authorized result reading. A key cannot submit answers as another person or replace participant sign-in.
