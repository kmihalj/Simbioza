# Pour les développeurs — API

<a id="for-developers--api"></a>


> Les captures d’écran présentent l’interface en anglais.

[Sondages](ankete_fr.md)

Cette section est destinée à l'intégration d'autres systèmes avec Simbioza. L’API n’est pas requis pour la création ou la participation ordinaire.

1.  [API — exemples cURL](ankete-api_fr.md)
2.  [API — PHP exemples pour votre application](ankete-api-php_fr.md)
3.  [Itinéraires, étendues et erreurs](ankete-api-referenca_fr.md)
4.  [Modèle de définition et exemples de réponses](ankete-api-primjeri_fr.md)
5.  [Contenu HTML et limite de sécurité](ankete-html-sadrzaj_fr.md)

Les exemples utilisent l'espace réservé `https://simbioza.example`. Remplacez-le par votre adresse d'installation et n'importe quel sous-répertoire. Ni HFC ni sondages d’échantillons préexistants ne sont requis.

L’API gère les définitions, la publication et la lecture des résultats autorisés. Une clé ne peut pas soumettre de réponses en tant qu'autre personne ni remplacer la connexion d'un participant.
