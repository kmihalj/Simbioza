General settings, authentication and permissions are separate under **Settings → Surveys**. Do not grant administrator access merely so someone can create surveys.

## Restore a survey from trash

Under **Settings → Surveys → General settings**, open **Surveys · Trash**. Find the survey, read and check the confirmation, then choose **Restore survey**. Only an administrator can view and use recovery. A never-published survey returns as a draft; a previous publication returns closed. Check access, responses and report schedules, and approve publication separately when appropriate. Recovery does not reopen response collection or re-enable a disabled report schedule.
