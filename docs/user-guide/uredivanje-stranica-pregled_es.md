# Editar páginas

## En un espacio de trabajo

Abra **Espacios de trabajo**, elija un espacio y seleccione **Nueva página** junto a su árbol. Introduzca un título y elija su ubicación en el árbol. Si están disponibles ambos editores, seleccione **HTML** o **Markdown** en **Formato de página**. Si solo hay un editor, Simbioza selecciona su formato automáticamente. Pulse **Crear y editar**.

Para una página existente, pulse el lápiz **Editar**. Simbioza abre el editor correspondiente al formato de la página.

## Fuera de un espacio de trabajo

Si tiene acceso a la configuración del **editor HTML** o del **editor Markdown**, seleccione **Abrir editor**. En el editor independiente, pulse **Abrir** para un documento existente o **Crear** para uno nuevo. Algunas instalaciones también ofrecen el editor HTML mediante la opción **Páginas HTML** del menú.
