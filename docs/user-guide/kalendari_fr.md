# Calendriers — par où commencer

<a id="calendars--where-to-start"></a>


> Les captures d’écran présentent l’interface en anglais.

Les calendriers réunissent les événements que vous avez le droit de consulter. Utilisez-les pour les annonces publiques, les plannings d’équipe, les salles et les équipements ou vos engagements personnels.

<a id="types-and-roles"></a>
<a id="differences"></a>
<a id="what-would-you-like-to-do"></a>

## Que souhaitez-vous faire ?

| Objectif | Guide |
| --- | --- |
| Lire un planning, changer de vue ou choisir les calendriers | [Vues et abonnements](kalendari-pregled_fr.md) |
| Ajouter un créneau, modifier un événement ou définir sa répétition | [Événements](kalendari-dogadaji_fr.md) |
| Créer et partager votre propre calendrier | [Calendriers personnels](kalendari-osobni_fr.md) |
| Transférer un fichier ICS ou connecter une application de calendrier | [Importation, exportation et CalDAV](kalendari-povezivanje_fr.md) |
| Inviter des participants et convenir d’un horaire ou réserver un créneau | [Réunions](sastanci_fr.md) |
| Gérer les calendriers partagés et leurs droits | [Administration des calendriers](admin-kalendari_fr.md) |

Le droit de **Lecture** permet de consulter les événements. Le droit d’**Écriture** permet d’ajouter, de modifier et de supprimer les événements du calendrier. Il ne permet pas automatiquement de modifier le nom, la visibilité publique ou les droits d’un calendrier partagé.

Un calendrier public est accessible aux visiteurs non connectés ; un calendrier d’équipe contient les événements partagés, un calendrier de ressource représente une salle ou un équipement et un calendrier personnel appartient à un utilisateur. Chaque type respecte les droits enregistrés et son état actif ou inactif.

## Je souhaite seulement lire le planning

Vous n’avez pas besoin d’un compte administrateur. Les visiteurs non connectés voient les calendriers publics ; les utilisateurs connectés voient également les calendriers qu’ils ont le droit de consulter. [Le guide de consultation](kalendari-pregled_fr.md) présente les filtres, les couleurs, les abonnements, les vues d’un seul calendrier et l’utilisation sur téléphone.

## Je souhaite ajouter des événements

Vous devez disposer d’un droit d’écriture sur au moins un calendrier. Créez votre calendrier personnel dans **Paramètres du calendrier**. Pour travailler dans le calendrier d’une autre personne, demandez le droit nécessaire à son propriétaire ou à son responsable.

<a id="administration"></a>
<a id="permissions"></a>

## Je gère les calendriers d’autres utilisateurs

L’administrateur de l’installation ouvre **Paramètres → Calendriers → Administration des calendriers**. Les membres du groupe système **Calendars** utilisent **Calendriers → Gérer les calendriers partagés** ; cette appartenance ne donne pas accès à tous les paramètres ni aux calendriers personnels d’autres personnes. Suivez [le guide d’administration](admin-kalendari_fr.md).

<a id="verification"></a>
<a id="if-something-is-missing"></a>

## Un élément manque

Vérifiez la période affichée, la case du calendrier et votre abonnement. Si le calendrier n’apparaît toujours pas, demandez à son responsable de vérifier son état actif et votre droit de lecture. Si vous pouvez consulter les événements sans pouvoir en ajouter, renseignez-vous sur le droit d’écriture.
