# Arbeitsbereiche – der Einstieg

<a id="workspaces--where-to-start"></a>


> Die Bildschirmaufnahmen zeigen die englische Benutzeroberfläche.

Ein Arbeitsbereich enthält verwandte Seiten: zum Beispiel ein Projekt, eine Abteilung oder eine Reihe von Anweisungen. Es verfügt über einen Seitenbaum, Inhalte und Zugriffsberechtigungen. **Die Möglichkeit, einen Arbeitsbereich zu öffnen, bedeutet nicht, dass Sie jede Seite darin bearbeiten können.**

Wählen Sie, was Sie tun möchten. Wenn eine Aktion fehlt, überprüfen Sie Ihr Konto und bitten Sie den Arbeitsbereichs-Manager, Ihre Berechtigungen zu überprüfen.

## Ich möchte meinen Arbeitsbereich organisieren

| Aufgabe | Anleitung |
| --- | --- |
| Starten Sie einen Bereich für ein Projekt oder Team | [Arbeitsbereich erstellen](podrucja-stvaranje_de.md) |
| Ändern Sie den Namen, die Anzeige oder den Status | [Verwalten Sie Ihren Arbeitsbereich](podrucja-upravljanje_de.md) |

<a id="scenarios"></a>
Ein Manager pflegt den Arbeitsbereich, ein Redakteur ändert Inhalte und ein Herausgeber genehmigt die Veröffentlichung. Hierbei handelt es sich um separate Fähigkeiten, die gemeinsam oder einzeln zugewiesen werden können. Ein Leser sieht zugängliche veröffentlichte Inhalte; Durch das Speichern eines neuen Entwurfs wird dieser nicht automatisch ersetzt.
