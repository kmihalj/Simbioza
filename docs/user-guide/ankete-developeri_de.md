Dieser Abschnitt dient der Integration anderer Systeme mit Simbioza. Das API ist für die normale Autorenarbeit oder Teilnahme nicht erforderlich.

1.  [API – cURL-Beispiele](ankete-api_de.md)
2.  [API – PHP-Beispiele für Ihre Anwendung](ankete-api-php_de.md)
3.  [Routen, Scopes und Fehler](ankete-api-referenca_de.md)
4.  [Definitionsvorlage und Antwortbeispiele](ankete-api-primjeri_de.md)
5.  [HTML Inhalt und Sicherheitsgrenze](ankete-html-sadrzaj_de.md)

Beispiele verwenden den Platzhalter `https://simbioza.example`. Ersetzen Sie es durch Ihre Installationsadresse und ein beliebiges Unterverzeichnis. Es sind weder HFKW noch bereits bestehende Stichprobenerhebungen erforderlich.

Die API verwaltet Definitionen, Veröffentlichung und autorisiertes Lesen der Ergebnisse. Ein Schlüssel kann keine Antworten als andere Person einreichen oder die Anmeldung eines Teilnehmers ersetzen.
