# Para autores de encuestas

<a id="for-survey-authors"></a>


> Las capturas de pantalla muestran la interfaz en inglés.

[Encuestas](ankete_es.md)

Esta sección es para personas que escriben preguntas y revisan respuestas. No necesita conocimientos de programación ni acceso a la configuración de inicio de sesión externo.

<a id="your-first-survey"></a>

## Tu primera encuesta

1.  [Crear un borrador](ankete-izrada-objava_es.md): elija un título y un idioma principal.
2.  [Agregue una introducción y preguntas](ankete-pitanja_es.md): explique el propósito e ingrese las opciones.
3.  [Elija quién puede participar](ankete-pristup-privatnost_es.md) — acceso y anonimato.
4.  [Verificar y enviar para publicación](ankete-objava_es.md): solo una encuesta publicada acepta respuestas.
5.  [Ver los resultados](ankete-rezultati_es.md): gráficos, envíos y notificaciones.

**Ejemplo utilizado en esta guía:** “Su experiencia en el taller” tiene una breve introducción, una pregunta de elección, una calificación de 1 a 5 y un comentario opcional.
