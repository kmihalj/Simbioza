<a id="restore-a-survey-from-trash"></a>

## Stellen Sie eine Umfrage aus dem Papierkorb wieder her

Öffnen Sie unter **Einstellungen → Umfragen → Allgemeine Einstellungen** **Umfragen · Papierkorb**. Suchen Sie die Umfrage, lesen und überprüfen Sie die Bestätigung und wählen Sie dann **Umfrage wiederherstellen**. Nur ein Administrator kann die Wiederherstellung anzeigen und verwenden. Eine nie veröffentlichte Umfrage erscheint als Entwurf; eine frühere Veröffentlichung wird geschlossen zurückgegeben. Überprüfen Sie Zugriff, Antworten und Berichtszeitpläne und genehmigen Sie die Veröffentlichung gegebenenfalls separat. Die Wiederherstellung öffnet die Antwortsammlung nicht erneut und aktiviert einen deaktivierten Berichtszeitplan nicht erneut.
