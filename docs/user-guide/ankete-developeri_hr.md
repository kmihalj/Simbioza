Primjeri koriste zamjensku adresu `https://simbioza.example`. Zamijenite je vlastitom adresom i poddirektorijem ako ga instalacija koristi. Ne trebaju vam HFC niti postojeće ogledne ankete.

API je za upravljanje definicijama, objavu i dopušteno čitanje rezultata. Ključ ne služi predaji odgovora u tuđe ime niti zamjenjuje prijavu ispitanika.
