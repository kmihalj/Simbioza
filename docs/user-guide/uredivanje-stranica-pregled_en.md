# Editing pages

## In a workspace

Open **Workspaces**, select a workspace and choose **New page** beside its page tree. Enter a title and choose where the page belongs in the tree. If both editors are available, select **HTML** or **Markdown** under **Page format**. If one editor is available, Simbioza selects its format automatically. Choose **Create and edit**.

For an existing page, choose the **Edit** pencil. Simbioza opens the editor that matches the page's format.

## Outside a workspace

In **HTML Editor** or **Markdown Editor** settings, choose **Open editor** if you have access to those settings. In the standalone editor, choose **Open** for an existing document or **Create** for a new one. Some installations also make the HTML editor available from **HTML pages** in the menu.
