# Für Umfrageautoren

<a id="for-survey-authors"></a>


> Die Bildschirmaufnahmen zeigen die englische Benutzeroberfläche.

[Umfragen](ankete_de.md)

Dieser Abschnitt richtet sich an Personen, die Fragen schreiben und Antworten überprüfen. Sie benötigen keine Programmierkenntnisse oder Zugriff auf die externe Anmeldekonfiguration.

<a id="your-first-survey"></a>

## Ihre erste Umfrage

1.  [Entwurf erstellen](ankete-izrada-objava_de.md) – Wählen Sie einen Titel und eine Hauptsprache.
2.  [Einleitung und Fragen hinzufügen](ankete-pitanja_de.md) – Erklären Sie den Zweck und geben Sie Auswahlmöglichkeiten ein.
3.  [Wählen Sie, wer teilnehmen kann](ankete-pristup-privatnost_de.md) – Zugang und Anonymität.
4.  [Überprüfen und zur Veröffentlichung einreichen](ankete-objava_de.md) – nur eine veröffentlichte Umfrage akzeptiert Antworten.
5.  [Ergebnisse anzeigen](ankete-rezultati_de.md) – Diagramme, Einreichungen und Benachrichtigungen.

**In diesem Leitfaden verwendetes Beispiel:** „Ihre Workshop-Erfahrung“ enthält eine kurze Einleitung, eine Auswahlfrage, eine Bewertung von 1–5 und einen optionalen Kommentar.
