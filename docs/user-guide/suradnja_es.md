# Colaborar en los contenidos

<a id="working-together-on-content"></a>


> Las capturas de pantalla muestran la interfaz en inglés.

Simbioza conecta páginas compartidas con debates, listas de tareas y notificaciones. Elija la acción que necesita; no es necesario ser administrador.

| Meta | Guía |
| --- | --- |
| Escribe un comentario o reacciona a uno. | [Comentarios](komentari_es.md) |
| Agregar tareas a una página o marcar el trabajo como completo | [Tareas](zadaci_es.md) |
| Siga los cambios y elija la entrega por correo electrónico o desde la aplicación | [Seguimiento y notificaciones](pracenje-obavijesti_es.md) |
| Buscar contenidos publicados | [Buscar](pretraga_es.md) |
| Iniciar sesión o cambiar la configuración personal | [Mi perfil](osobni-profil_es.md) |

Las funciones dependen de los módulos habilitados y de sus permisos. Leer una página no permite editar automáticamente su texto y seguir el contenido no otorga acceso a información privada.

**Ejemplo:** un autor publica un plan de taller, un lector publica una pregunta, una persona autorizada marca la preparación como completa y los seguidores reciben el cambio a través del canal seleccionado. Guardar un borrador inédito no es una publicación nueva para los seguidores.
