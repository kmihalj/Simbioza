# Gemeinsam an Inhalten arbeiten

<a id="working-together-on-content"></a>


> Die Bildschirmaufnahmen zeigen die englische Benutzeroberfläche.

Simbioza verbindet freigegebene Seiten mit Diskussionen, Aufgabenlisten und Benachrichtigungen. Wählen Sie die Aktion aus, die Sie benötigen. Sie müssen kein Administrator sein.

| Ziel | Anleitung |
| --- | --- |
| Schreiben Sie einen Kommentar oder reagieren Sie darauf | [Kommentare](komentari_de.md) |
| Fügen Sie Aufgaben zu einer Seite hinzu oder markieren Sie die Arbeit als abgeschlossen | [Aufgaben](zadaci_de.md) |
| Verfolgen Sie die Änderungen und wählen Sie die Zustellung per E-Mail oder In-App | [Folgen und Benachrichtigungen](pracenje-obavijesti_de.md) |
| Finden Sie veröffentlichte Inhalte | [Suchen](pretraga_de.md) |
| Melden Sie sich an oder ändern Sie persönliche Einstellungen | [Mein Profil](osobni-profil_de.md) |

Die Funktionen hängen von aktivierten Modulen und Ihren Berechtigungen ab. Das Lesen einer Seite ermöglicht nicht automatisch die Bearbeitung ihres Textes und das Verfolgen von Inhalten gewährt keinen Zugriff auf private Informationen.

**Beispiel:** Ein Autor veröffentlicht einen Workshop-Plan, ein Leser stellt eine Frage, eine autorisierte Person markiert die Vorbereitung als abgeschlossen und Follower erhalten die Änderung über den von ihnen ausgewählten Kanal. Das Speichern eines unveröffentlichten Entwurfs ist keine neue Veröffentlichung für Follower.
