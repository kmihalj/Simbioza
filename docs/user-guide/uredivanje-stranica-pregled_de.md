# Seiten bearbeiten

## In einem Arbeitsbereich

Öffnen Sie **Arbeitsbereiche**, wählen Sie einen Arbeitsbereich und klicken Sie neben dem Seitenbaum auf **Neue Seite**. Geben Sie einen Titel ein und legen Sie die Position im Baum fest. Sind beide Editoren verfügbar, wählen Sie unter **Seitenformat** **HTML** oder **Markdown**. Ist nur ein Editor verfügbar, wählt Simbioza dessen Format automatisch. Klicken Sie auf **Erstellen und bearbeiten**.

Bei einer vorhandenen Seite klicken Sie auf das Stiftsymbol **Bearbeiten**. Simbioza öffnet den Editor für das Format der Seite.

## Außerhalb eines Arbeitsbereichs

Wenn Sie Zugriff auf die Einstellungen des **HTML Editors** oder **Markdown Editors** haben, wählen Sie dort **Editor öffnen**. Im eigenständigen Editor öffnen Sie mit **Öffnen** ein vorhandenes Dokument oder erstellen mit **Erstellen** ein neues. In manchen Installationen ist der HTML Editor auch über **HTML-Seiten** im Menü erreichbar.
