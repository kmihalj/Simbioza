# Modifier les pages

## Dans un espace de travail

Ouvrez **Espaces de travail**, choisissez un espace, puis sélectionnez **Nouvelle page** à côté de son arborescence. Saisissez un titre et choisissez sa position dans l’arborescence. Si les deux éditeurs sont disponibles, sélectionnez **HTML** ou **Markdown** dans **Format de la page**. Avec un seul éditeur, Simbioza sélectionne automatiquement son format. Cliquez sur **Créer et modifier**.

Pour une page existante, cliquez sur le crayon **Modifier**. Simbioza ouvre l’éditeur correspondant au format de la page.

## Hors d’un espace de travail

Si vous avez accès aux paramètres de l’**éditeur HTML** ou de l’**éditeur Markdown**, sélectionnez **Ouvrir l’éditeur**. Dans l’éditeur autonome, choisissez **Ouvrir** pour un document existant ou **Créer** pour un nouveau. Certaines installations proposent aussi l’éditeur HTML dans le menu **Pages HTML**.
