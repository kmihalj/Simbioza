# Kalender – der Einstieg

<a id="calendars--where-to-start"></a>


> Die Bildschirmaufnahmen zeigen die englische Benutzeroberfläche.

Kalender fassen die Ereignisse zusammen, die Sie möglicherweise lesen. Nutzen Sie sie für öffentliche Ankündigungen, Teampläne, Räume und Ausrüstung oder Ihre persönlichen Verpflichtungen.

<a id="types-and-roles"></a>
<a id="differences"></a>
<a id="what-would-you-like-to-do"></a>

## Was möchten Sie tun?

| Ziel | Anleitung |
| --- | --- |
| Lesen Sie einen Zeitplan, ändern Sie die Ansicht oder wählen Sie Kalender aus | [Aufrufe und Abonnements](kalendari-pregled_de.md) |
| Fügen Sie ein Zeitfenster hinzu, ändern Sie ein Ereignis oder legen Sie eine Wiederholung fest | [Ereignisse](kalendari-dogadaji_de.md) |
| Erstellen und teilen Sie Ihren eigenen Kalender | [Persönliche Kalender](kalendari-osobni_de.md) |
| Übertragen Sie eine ICS-Datei oder verbinden Sie eine Kalenderanwendung | [Import, Export und CalDAV](kalendari-povezivanje_de.md) |
| Laden Sie Teilnehmer ein und vereinbaren oder reservieren Sie einen Termin | [Besprechungen](sastanci_de.md) |
| Pflegen Sie freigegebene Kalender und deren Berechtigungen | [Kalenderverwaltung](admin-kalendari_de.md) |

**Lesen** ermöglicht das Anzeigen von Ereignissen. **Schreiben** ermöglicht das Hinzufügen, Ändern und Löschen von Ereignissen in diesem Kalender. Es ist nicht automatisch möglich, den Namen, die öffentliche Sichtbarkeit oder die Berechtigungen eines freigegebenen Kalenders zu ändern.

Den Gästen steht ein öffentlicher Kalender zur Verfügung; ein Teamkalender enthält gemeinsame Ereignisse, ein Ressourcenkalender stellt einen Raum oder eine Ausrüstung dar und ein persönlicher Kalender gehört einem Benutzer. Jeder Typ respektiert weiterhin seine gespeicherten Berechtigungen und seinen aktiven Status.

## Ich muss nur den Zeitplan lesen

Sie benötigen kein Administratorkonto. Gäste sehen öffentliche Kalender; Angemeldete Benutzer sehen auch Kalender, die sie lesen dürfen. [Der Anzeigeleitfaden](kalendari-pregled_de.md) behandelt Filter, Farben, Abonnements, Einzelkalenderansichten und mobile Nutzung.

## Ich muss Ereignisse hinzufügen

Sie benötigen Schreibzugriff auf mindestens einen Kalender. Erstellen Sie Ihren eigenen persönlichen Kalender über **Kalendereinstellungen**. Um im Kalender einer anderen Person zu arbeiten, bitten Sie den Eigentümer oder Manager um die entsprechende Berechtigung.

<a id="administration"></a>
<a id="permissions"></a>
<a id="i-maintain-other-users-calendars"></a>

## Ich pflege die Kalender anderer Benutzer

Der Installationsadministrator öffnet **Einstellungen → Kalender → Kalenderverwaltung**. Mitglieder der Systemgruppe **Kalender** verwenden **Kalender → Freigegebene Kalender verwalten**; die Mitgliedschaft gewährt nicht alle Einstellungen oder Zugriff auf die persönlichen Kalender anderer Personen. Befolgen Sie [die Administrationsanleitung](admin-kalendari_de.md).

<a id="verification"></a>
<a id="if-something-is-missing"></a>

## Wenn etwas fehlt

Überprüfen Sie den Datumsbereich, das Kalender-Kontrollkästchen und Ihr Abonnement. Wenn der Kalender immer noch nicht vorhanden ist, bitten Sie seinen Manager, seinen aktiven Status und Ihre Leseberechtigung zu überprüfen. Wenn Sie lesen, aber keine Ereignisse hinzufügen können, fragen Sie nach Schreibzugriff.
