# Workspaces — where to start

A workspace holds related pages: for example, a project, department or set of instructions. It has a page tree, content and access permissions. **Being able to open a workspace does not mean you may edit every page in it.**

Choose what you want to do. If an action is missing, check your account and ask the workspace manager to review your permissions.

<a id="scenarios"></a>
A manager maintains the workspace, an editor changes content, and a publisher approves publication. These are separate capabilities which may be assigned together or individually. A reader sees accessible published content; saving a new draft does not automatically replace it.
