Los ejemplos utilizan el marcador de posición `https://simbioza.example`. Reemplácelo con su dirección de instalación y cualquier subdirectorio. No se requieren HFC ni encuestas por muestreo preexistentes.

El API gestiona definiciones, publicación y lectura de resultados autorizados. Una clave no puede enviar respuestas como otra persona ni reemplazar el inicio de sesión del participante.
