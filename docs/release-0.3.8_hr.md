# Simbioza 0.3.8 — neobjavljeni kandidat

> Povijesna bilješka izdanja. Za aktualne instalacijske upute koristite [instalacijsku uputu](installation_hr.md).

Tag 0.3.8 bilježi prijelaznog kandidata. GitHub izdanje nije objavljeno i za
njega nije objavljen stabilni Docker image. Završna provjera FPM Secured
instalacije otkrila je dodatni problem s pravima privatne konfiguracije.

Koristite [Simbiozu 0.3.10](release-0.3.10_hr.md), koja uključuje potpune ispravke
očuvanja postavki i boje teme. Tag 0.3.8 ostaje nepromijenjen; nemojte ga
koristiti kao cilj instalacije ili nadogradnje.
