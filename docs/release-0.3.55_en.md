# Simbioza 0.3.55 — default theme width

On new installations, the Simbioza theme uses centered containers with the same 1640 CSS pixel maximum width as Festival.

An upgrade applies this setting once and only when the installed theme settings exactly match the previous bundled Simbioza preset. Customized themes, other active theme choices, and local settings are preserved.

See [installation](installation_en.md), [Docker deployment](docker_en.md) and the [theme collection](https://github.com/kmihalj/Simbioza/releases/download/0.3.55/Simbioza-0.3.55-themes.zip).
