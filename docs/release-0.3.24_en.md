# Simbioza 0.3.24 — original gradients and optional text shadows

> Historical release notes. See the [current installation guide](installation_en.md) and [Simbioza 0.3.27](release-0.3.27_en.md).

[Croatian version](release-0.3.24_hr.md)

Hero, navigation and mobile drawer gradients again use the exact theme colors. Automatic darkening and lightening introduced in 0.3.23 are removed. Existing and new themes default to **No shadow**; text color, font weight and the background are preserved.

Theme settings now offer independent choices for title, supporting text and menu text: No shadow, Soft shadow or Contrasting outline. Changes appear immediately in the light and dark previews. Saving, copying and portable export retain these choices.

This release includes Theme 0.3.6. Other module versions, Auth, Framework and database migrations are unchanged. All six language packs include the new controls. Existing selections of installed languages are preserved.

Use the secured-FPM GUI or the documented CLI updater. Docker uses `ghcr.io/kmihalj/simbioza:0.3.24` with existing persistent volumes. See [installation](installation_en.md), [module inventory](module-dependencies_en.md) and [Docker](docker_en.md).
