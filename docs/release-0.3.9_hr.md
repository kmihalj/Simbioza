# Simbioza 0.3.9 — neobjavljeni kandidat

> Povijesna bilješka izdanja. Za aktualne instalacijske upute koristite [instalacijsku uputu](installation_hr.md).

Tag bilježi provjerenog prijelaznog kandidata, ne objavljeno izdanje. Završni
pregled očuvanja konfiguracije zahtijevao je dodatne ispravke navigacije u
modulima Email, HTML Editor, Auth i Menu.

Koristite [Simbiozu 0.3.10](release-0.3.10_hr.md). Postojeći tagovi ostaju
nepromijenjeni; 0.3.9 nije preporučeni cilj instalacije ili nadogradnje.
