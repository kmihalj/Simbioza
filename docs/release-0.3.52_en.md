# Simbioza 0.3.52 — fullscreen editing

MD Editor **0.3.2** and HTML Editor **0.3.23** keep the toolbar visible in fullscreen. When the theme uses a sticky header or navigation, the editing frame starts immediately below it. Both the visual and source views fill the remaining space, and long documents scroll inside the editor to the last line.

Fullscreen editing was checked with Accessibility enabled and text at 125%. This release includes the guides for both editors from [0.3.51](release-0.3.51_en.md).

See [installation](installation_en.md), [Docker deployment](docker_en.md) and the [theme collection](https://github.com/kmihalj/Simbioza/releases/download/0.3.52/Simbioza-0.3.52-themes.zip).
