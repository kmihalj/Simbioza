# Simbioza 0.1.91

Ovo održavateljsko izdanje ispravlja prikaz dostupnih nadogradnji opcionalnih modula. Provjera sada poštuje dopuštene raspone verzija iz Simbiozina kataloga opcionalnih modula i odbacuje nekompatibilne spremljene rezultate. Zato se povijesni tag Teme `v1.0.0` više ne prikazuje kao nadogradnja instalacije koja koristi aktualnu liniju `0.1.x`. Sam modul Teme ostaje na verziji `0.1.17`; njegov povijesni tag nije promijenjen.

Izdanje uključuje i Pristupačnost `0.1.1`, u kojoj korisnikov odabir isticanja poveznica nadjačava stil navigacije koji inače uklanja podcrtavanje. Nema novih migracija baze ni ručne promjene konfiguracije. Postojeći jezici, stanje modula, postavke teme i autorski sadržaj ostaju podaci instalacije. Upotrijebite podržani GUI ili CLI postupak nadogradnje aplikacije.
