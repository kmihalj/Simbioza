# Simbioza 0.3.24 — izvorni gradijenti i neobavezne sjene teksta

[Engleska verzija](release-0.3.24_en.md)

Gradijenti zaglavlja, navigacije i mobilnog izbornika ponovno koriste točne boje teme. Uklonjeno je automatsko zatamnjivanje i posvjetljivanje uvedeno u 0.3.23. Postojeće i nove teme zadano koriste **Bez sjene**; čuvaju se boja teksta, debljina fonta i pozadina.

Postavke teme sada odvojeno nude odabire za naslov, pomoćni tekst i tekst izbornika: Bez sjene, Blaga sjena ili Kontrastni obrub. Promjene se odmah vide u svijetlom i tamnom pregledu. Spremanje, kopiranje i prenosivi izvoz čuvaju te odabire.

Izdanje uključuje Theme 0.3.6. Verzije ostalih modula, Auth, Framework i migracije baze ostaju isti. Svih šest jezičnih paketa uključuje nove kontrole. Postojeći odabir instaliranih jezika ostaje sačuvan.

Koristite GUI za secured FPM ili dokumentirani CLI updater. Docker koristi `ghcr.io/kmihalj/simbioza:0.3.24` s postojećim trajnim volumenima. Vidi [instalaciju](installation_hr.md), [ovisnosti modula](module-dependencies_hr.md) i [Docker](docker_hr.md).
