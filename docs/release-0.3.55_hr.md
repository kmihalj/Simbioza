# Simbioza 0.3.55 — širina zadane teme

Zadana tema Simbioza na novim instalacijama koristi centrirane okvire maksimalne širine 1640 CSS piksela, kao Festival.

Pri nadogradnji se postavka primjenjuje jednom i samo ako spremljena tema točno odgovara prethodno isporučenoj temi Simbioza. Prilagođene teme, drugi odabiri aktivne teme i lokalne postavke ostaju sačuvani.

Pogledajte [instalaciju](installation_hr.md), [Docker](docker_hr.md) i [paket tema](https://github.com/kmihalj/Simbioza/releases/download/0.3.55/Simbioza-0.3.55-themes.zip).
